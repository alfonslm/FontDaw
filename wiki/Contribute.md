# Contribute

FontDaw is free software and we welcome help.

## Ways to help

FontDaw is free software under the GNU General Public License version 3, so you may study, change and share it.

- **Code:** the code style is checked with a formatting tool. Keep the existing copyright and licence notices in any file you change. New FontDaw files carry FontDaw's GPLv3 header.
- **Translation:** every text the program shows can be translated. There is no way to send translations yet.

Opening newer files

What to do when FontDaw says a file was saved by a newer version.

What the message means

A score that was saved by a newer program than yours can use features that your version does not know. FontDaw then refuses to open it and shows a box called Cannot read file, with the file's location and the message "This file uses a newer version of the file format than this program can read."

The score is not opened and nothing is changed. There is no "open anyway" choice for this message.

To open the file, use a version of FontDaw that is at least as new as the program that saved it, or ask whoever made the file for a copy saved in an older format, such as MusicXML.

Stub: whether FontDaw can save in an older format has not been checked.

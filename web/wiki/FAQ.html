FAQ

Short answers to the questions we expect most. If yours is missing, see Get help.

Can I download FontDaw?

Not yet. It is at version 0.1.0 and there are no public builds. See Getting FontDaw.

Is it free?

Yes. FontDaw is free software under the GNU General Public License version 3. See Licence and credits.

Is FontDaw MuseScore?

No. It is based on MuseScore Studio's code, but it is a separate project. It is not affiliated with or endorsed by MuseScore Limited or Muse Group. See FontDaw and MuseScore.

Can it open my MuseScore files?

Yes, up to the version of MuseScore that FontDaw is based on. A file saved by a newer MuseScore can be refused: see Opening newer files. The reverse is not guaranteed: MuseScore may ignore the audio in a FontDaw project. See files and formats.

Can I have both installed?

That is the design: FontDaw keeps its own settings and folders so that it does not touch MuseScore Studio's. There are no installers yet, and we have not tested having both on one computer.

Do I need an account or an internet connection?

No. FontDaw makes no network connections of its own. See Privacy.

Does it work with Muse Sounds?

No. Muse Sounds needs a closed-source library and Muse Group's online services. FontDaw plays with SoundFonts and VST3 instruments.

Can I record audio?

Not yet. Recording is on the plan. You can import WAV, FLAC, MP3 and Ogg files today: see Audio tracks.

Which systems will it run on?

We plan packages for Windows, macOS and Linux. There are no installers yet and we have not published system requirements.

When is 1.0?

We have no date. Status and roadmap says what 1.0 means and what comes first.

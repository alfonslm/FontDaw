# FontDaw

**The notation-first DAW.**

FontDaw is a music workstation built around the score: write music in standard notation,
then record, arrange and mix audio around it in the same project.

> **Status: early development.** Nothing to download yet.

Website: <https://alfonslm.github.io/FontDaw/>

## Background

FontDaw is based on [MuseScore Studio](https://github.com/musescore/MuseScore) by MuseScore
Limited and contributors. FontDaw is not affiliated with or endorsed by MuseScore Limited or
Muse Group.
